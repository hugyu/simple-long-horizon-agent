# Agent 技术面试准备

本目录独立保存面试问题、回答准则和专题口述底稿，不属于 `docs/` 中的项目设计与开发
文档。面试回答仍以当前代码、测试、项目文档、简历描述和已发布结果为事实依据。

## 使用顺序

1. 阅读[简历项目描述](../docs/design/15-resume-project-description.md)，统一项目事实与结果口径。
2. 阅读[回答准则](answer-guidelines.md)，了解候选人模式、教练模式和事实边界。
3. 使用[问题清单](question-checklist.md)进行逐题练习。
4. 对照已有专题回答检查表达和技术深度，不需要逐字背诵。
